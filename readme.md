# 💰 Simulador de Investimentos em Fundos Imobiliários

Ferramenta educacional desenvolvida em Excel para simular investimentos mensais em fundos imobiliários.

## Funcionalidades
- Projeção patrimonial de até 30 anos
- Cálculo dos dividendos mensais
- Comparação de diferentes prazos
- Sugestão de aporte com base no salário
- Alocação por perfil Conservador, Moderado ou Agressivo
- Gráficos de patrimônio e distribuição do investimento

## Como utilizar
1. Baixe o arquivo Excel.
2. Abra a aba `APP`.
3. Preencha as células azuis.
4. Escolha o perfil de investimento.
5. Consulte os resultados, cenários e gráficos.

## Aviso
Este projeto possui finalidade exclusivamente educacional. As simulações não constituem recomendação de investimento nem garantia de rentabilidade.
